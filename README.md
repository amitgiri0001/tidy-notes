# Tidy Notes

One tap turns rough, shorthand notes into clean sentences — without changing what you wrote.

- Fixes spelling, grammar, punctuation, capitalisation
- Never adds, removes or reorders ideas; keeps bullets, links, tags, code and frontmatter intact
- Works on selection, or the whole note if nothing is selected
- Undo restores the original
- Desktop and mobile

## Use
- Ribbon icon (sparkles), or
- Command palette: "Tidy selection (or whole note)" — pin it to the mobile toolbar, or
- Right-click → "Tidy text"

## Setup
Settings → Tidy Notes → paste an Anthropic API key.

## Disclosure
- **Network:** text you tidy is sent to `api.anthropic.com`. Nothing else is sent.
- **Account:** requires your own Anthropic API key (paid, usage-based).
- The key is stored in plain text in `.obsidian/plugins/tidy-notes/data.json`.
